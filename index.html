校核

    填好空间高度、内径和要的力，下面会出现一批能做的方案。

    线径 d外径 D圈数 n螺距 t自由长 L0 刚度 k行程力 F应力 τ利用率
      公式与名词

      刚度　k = G·d⁴ / (8·Dm³·n)　—— 线径是四次方：细一点点，立刻软很多

      应力　τ = K·8·F·Dm / (π·d³)　　K = (4C−1)/(4C−4) + 0.615/C

      压簧　t = (L0 − 2d)/n　　Ls = (n+2)·d

      拉簧　n = round(Lb/d)　　t = d

      弹簧指数 C = 中径 ÷ 线径：弹簧的"胖瘦"。C 太小（<4）丝太粗、卷不动，内侧应力尖；C 太大（>16）太软发晃。5–10 最好做。

      许用切应力：钢丝能承受的应力上限，超了就永久变形或者断。它 = 材料强度 ÷ 安全系数，随牌号、丝径、静载还是几百万次疲劳而变，所以必须按实际工况填，别照抄默认值。

      单位一律 mm / N / MPa。小变形线性假设，两端并紧磨平。
